# PackSketcher User Guide (Quick Start)

## What You Manage in PackSketcher
- **Workspace**: your background board
- **Box**: storage zone on the workspace
- **Item**: thing stored inside a box

## 5-Minute Start
1. Open **Dashboard**.
2. Create a workspace:
   - Click **Use this template**, or
   - Click **Upload Custom Background**.
3. Open the workspace card.
4. Click **Edit**.
5. Click **+ Add box**.
6. Drag/resize the box.
7. Open box details:
   - Desktop: double-click selected box
   - Mobile: double-tap selected box
8. Add item names, descriptions, and weights.
9. Click **Save** in Box Settings.

## Core Actions

### Workspaces
- Create from template
- Upload custom background
- Rename workspace
- Delete workspace (confirmation required)

### Boxes
- Add box (Edit mode only)
- Move and resize
- Reorder (desktop context menu)
- Delete with confirmation

### Items
- Add/edit/remove inside box details
- Bulk move between boxes/workspaces (with undo when available)

## Mobile Gestures
- Two fingers: pan/zoom workspace
- One finger: interact with selected box in Edit mode
- Double-tap selected box: open details

## Search
- Use **Global Item Search** on dashboard
- Finds items across workspaces and jumps to the matching workspace/box

## Save Behavior
- Box details use **Save / Cancel**
- Unsaved changes prompt appears before risky actions

## Troubleshooting
- "Can't edit": make sure **Edit mode** is on
- "No search results": type at least 3 characters
- "Name already exists": workspace/box/item names must be unique in scope
- "Changes not saved": check the inline error and retry

## Terms
- Workspace = board/background
- Box = area/container
- Item = entry inside a box
